Star-based Navigation — Alt/Az

Input: latitude φ, longitude λ, time. The datetime input shows local time but calculations use UTC. Output: Hour Angle, Altitude (h) and Azimuth (A) for selected bright stars.
Note: the browser shows the datetime-local in local time; the code treats the input as an absolute instant and uses UTC values for astronomical calculations.
Star RA α (hours) Dec δ (°) Hour Angle H (°) Altitude h (°) Azimuth A (°)
Model: JD → GMST (Meeus) → LST → H = LST − α → Alt/Az. Simplifications: no precession, nutation, proper motion or parallax. Bennett refraction is optional.
